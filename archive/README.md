# التجارب الأصلية

`Ax=b.ipynb` هو الدفتر الأصلي الذي كان غير متتبَّع في Git قبل التنظيم.
احتُفظ بجميع خلاياه الـ43 وبترتيبها، وأُضيفت خلية شرح في البداية.
تغيّرت خليتان برمجيتان فقط:

- محاولة `np.linalg.solve` للمصفوفة المنفردة تلتقط `LinAlgError` المتوقع وتطبعه.
- محاولة LU تلتقط تحذير التفرد بدل عرض قيم غير صالحة كحل؛ تكون `x_2_sc = None`
  عند فشل الحل، ثم تُعرض كما في الخلية التالية الأصلية.

بقية مصادر الخلايا محفوظة كما كانت. أُعيد توليد المخرجات بالتشغيل المتسلسل من نواة جديدة.
الضرب `u @ v.T` في تجربة الفضاءات حاصل ضرب خارجي؛ الخلايا اللاحقة تستخدم
`.dot()` لفحص التعامد. الشرح الموسّع موجود في الدفتر المنظّم داخل `notebooks/`.

قبل النقل والتعديل حُفظت نسختان مطابقتان للملفين الأصليين، مع بصمات SHA-256،
خارج هذا المستودع في مجلد عمل محادثة Codex:
`work/linearalgebra-before-organization/`.
